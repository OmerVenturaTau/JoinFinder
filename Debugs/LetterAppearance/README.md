# Geniza letter appearance debug

This diagnostic counts aleph (`א`), medial mem (`מ`), and the other Hebrew
letters in sampled Geniza ALTO OCR, then compares their raw confidence scores.

It measures:

- unfiltered recognized-glyph counts and empirical probabilities;
- raw ALTO glyph confidence (`GC`) as 5th–95th percentile and interquartile
  intervals per letter, with mean and median markers. Its display range is the
  global mean minus three standard deviations through the observed maximum; a
  conventional box plot on the same scale is also saved as a secondary view.

By default, no glyph-confidence filter or threshold is applied.

To reproduce the training glyph-confidence cutoff, enable the filter toggle:

```bash
python Debugs/LetterAppearance/analyze_geniza_letters.py \
  --source geniza \
  --apply-confidence-filter
```

This uses the configured `OCR_GLYPH_CONFIDENCE_THRESHOLD` (currently `0.92`).
Use `--confidence-threshold` to override it. Filtered results go to a separate
`<source>_letters_filtered/` directory by default.

Database sampling randomly chooses manuscripts first and then takes the same
maximum number of pages from each. Choose the collection with `--source`:

```bash
python Debugs/LetterAppearance/analyze_geniza_letters.py \
  --source geniza \
  --manuscripts 50 \
  --pages-per-manuscript 3
```

For the pretraining collection, use `--source pretraining`. A fresh random seed
is generated by default and saved in `analysis_config.json`; pass `--seed` to
reproduce an earlier selection exactly.

The DB sampler fetches a random reserve pool (twice the requested manuscript
count by default). Each manuscript contributes no more than
`--pages-per-manuscript` pages. Unusable pages are recorded in
`rejected_candidates.csv`, and their slots are filled from additional random
manuscripts. The final DB-backed sample therefore has exactly
`--manuscripts * --pages-per-manuscript` usable pages and reports zero skipped
pages. Increase `--candidate-multiplier` if the reserve is too small for an
unusually strict filter.

The count chart uses larger presentation fonts and includes a dashed line for
the mean glyph count across letter classes. The report also gives mean glyphs
per analyzed page.

To analyze an explicit reproducible sample without a database, pass a CSV with
at least `manuscript_id,xml_path`:

```bash
python Debugs/LetterAppearance/analyze_geniza_letters.py \
  --input-csv pages.csv \
  --output-dir Debugs/LetterAppearance/outputs/my_sample
```

By default final mem (`ם`) remains a separate class. Use
`--merge-final-forms` to merge all five final forms into their base letters.

The default output directory is `Debugs/LetterAppearance/outputs/geniza_letters/`
or `outputs/pretraining_letters/`, according to the selected source. Its
generated `README.md` contains a compact aleph/mem comparison.
