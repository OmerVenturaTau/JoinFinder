# debug_tools/Visualization

Visualization scripts for inspecting extraction and preprocessing.

- `visualize_all_for_manuscript.py`: DB-backed extraction summary and grids for a
  selected manuscript/image.
- `random_tiles_glyphs_grid.py`: quick grid generation for random extracted tiles
  and glyphs.
- `outputs/`: generated examples.

These scripts are useful before changing XML extraction, glyph tightening, or tile
selection logic.
